# Day 1 - Python Basics

## What I Learned

### 1. What is Python?
- Python is simple and easy to learn.
- It is a free and open-source language.
- Python is a high-level programming language.
- Python was developed by Guido van Rossum.
- Python is portable.

### 2. First Python Program

```python
print("Hello World")
```

### 3. Variables

A variable is a name given to a memory location in a program

```python
name = "Rithika"
age = 20
marks = 85.5
print(name)
print(age)
print(marks)
```

### 4. Datatypes

Python has different data types:

- Integer
- String
- Float
- Boolean
- None

Example:
```python
age = 20
name = "Rithika"
marks = 85.5
passed = True

print(type(age))
print(type(name))
print(type(marks))
print(type(passed))
```

### 5. Keywords

### 6. Comments

Comments are used to write notes in Python code.

Single-line comment:

# This is a comment
print("Hello")

Multi-line comment:

"""
This is a
multi-line comment
"""

### 7. Operators

An operator is a symbol that performs a certain operation between operands.

Arithmetic Operators
+ - * / % **

Relational / Comparison Operators
== != > < >= <=

Assignment Operators
= += -= *= /= %= **=

Logical Operators
not and or
